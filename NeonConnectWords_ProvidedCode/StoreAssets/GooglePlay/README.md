- `icon/`

- `screenshots/phone/`
- `screenshots/7-inch-tablet/`
- `screenshots/10-inch-tablet/`
- `copy/short-description.txt`
- `copy/full-description.txt`

Suggested working files:

- raw gameplay screenshots
- cropped store-ready screenshots
- short and full description drafts
- release notes drafts

Keep final exported store assets in this folder structure so releases are repeatable.
