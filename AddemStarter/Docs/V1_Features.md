# Addem v1 (Minimal + Useful)

## Core goals
- Save links in one click.
- Auto-organize pasted text into URL/title/tags/notes.
- Open important links fast from app or widget.

## v1 features
- Add link form: paste URL or mixed text.
- Link fields: URL, title, tags, notes, pinned.
- Auto-tagging: domain + keyword tags from title/notes.
- Search: by title, URL, notes, tags.
- Tag filter chips.
- Pin/unpin links.
- Open link and track last opened timestamp.
- Menu bar quick capture.
- Widget: shows pinned links (fallback to recent).
- Local persistence: JSON in shared App Group container.
