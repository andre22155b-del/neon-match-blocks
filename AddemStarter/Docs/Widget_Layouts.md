# Widget Layout Options

## Option 1: Pinned List (Implemented)
- Small: app title + 2 pinned links.
- Medium: app title + 4 pinned links.
- Best for quick opening.

## Option 2: Mixed Cards
- Small: top pinned + count of remaining links.
- Medium: 2-column compact cards with title + tag.
- Best when you want glanceable variety.

## Option 3: Focus + Queue
- Small: one "focus" pinned link + domain chip.
- Medium: focus link on left, 3-item queue on right.
- Best when you prioritize one active task.
